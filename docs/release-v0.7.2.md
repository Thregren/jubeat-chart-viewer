# v0.7.2

本版重做按键音：音色收敛为「点击」「太鼓」两组，每组按普通、16 分及更密、同押三档分别适配，并把六档响度压到同一水平；「同押独立音效」改为默认开启。

> 这是**源码发布**：只提供 GitHub 自动生成的源码包，不含客户端安装包。轻量客户端与曲库包仍以 v0.7.1 为准。

---

## 一、按键音的分档与判定

- **只剩两组音色**：「点击」（纯合成，880 Hz 方波族）与「太鼓」（沿用 `se/don.ogg`、`se/ka.ogg` 素材，缺素材时回落到合成音）。拍手、比利·海灵顿、彩虹猫 Nyan 与按拍位轮换的重音／普通双音一并移除，不再需要 `-16`、`clap`、`billy-*`、`nyan` 之类素材文件。
- **三档覆盖全部音符**：`core.hitSoundKind()` 按 `同押 > 16 分及更密 > 普通` 的优先级给出档位。判定看谱面**原始拍位**而不是与上一颗音符的时间间隔，所以 BPM 变化、播放倍速、同押都不会改变判定结果。
- **「16 分及更密」的边界**：`isSixteenthOrFiner()` 用「不在八分网格上」作判据——1/4 拍（16 分）、1/8 拍（32 分）、1/3 拍（三连音）都进密集档；四分与八分位置虽然也能被 16 分网格整除，但它们已有更粗的归属，保留普通音。
- **每档独立设计**：三档由同族音色派生，靠音高、时长、重复次数和频谱区分（点击：单发 / 倍频双击 / 双音齐发；太鼓：素材原速 / 升调截短双击 / 加厚叠音），不再共用一组跨音色的「签名音」。一批同押只发一次。

## 二、响度对齐

- 旧的 `DynamicsCompressor` 方案被废弃：压缩器的自动 makeup 增益是规范行为，各家实现（尤其移动端 Safari）差异不可控。改为**纯静态传输曲线**：`bus → preGain 2.4 → tanh 软限幅（drive 1.5、ceiling 0.885、`oversample="none"`）→ master`，完全确定、跨引擎一致。
- 限幅是非线性的，因此 `SFX_LEVELS` 的语义是「限幅前预加重」而不是「表内等响」，系数用 `deploy-sfx/measure_static_loudness.mjs --solve` 迭代求解：

  ```js
  const SFX_LEVELS = {
    click: { normal: 1.284, sixteenth: 2.103, chord: 0.903 },
    taiko: { normal: 0.720, sixteenth: 3.878, chord: 0.948 },
  };
  const SAMPLE_AMP = 1.409;   // 素材路径与合成路径的电平对齐
  ```

- 离线实测（`OfflineAudioContext`，44.1 kHz / 0.5 s / 10 籽平均，取前 150 ms RMS，60% 音量）：**6 个合成档全部 ≈ −15.0 dB，最大差 0.09 dB**；把太鼓素材路径一起算进去共 9 项，最大差 1.34 dB；最坏峰值 −1.06 dB，不削波。整体比旧版高约 9 dB（≈2.8 倍），不需要再把音效音量开到 200%。

## 三、设置与界面

- 设置页「按键音效」只剩 关 / 点击 / 太鼓；「同押独立音效」为新增复选框，`index.html` 里直接带 `checked`，首帧不闪。
- **设置版本 8 → 9**：`savedSettingsVersion < 9` 的浏览器会清一次 `jubeat.chordSound` 并强制勾选——老用户存着的 `"0"` 几乎都是旧默认值，从没动过这个开关；清过一次之后照旧记住用户的选择。
- 旧音色值（`clap` / `billy` / `nyan` / 大小写变体）统一迁移为 `click` 并写回，避免升级后下拉框落到「关」、音效突然静音。
- 移除「试听三档」按钮；切换音色时自动试听该音色的普通档，打开同押开关时试听同押档。
- **分享页兼容**：分享页是构建时生成的静态快照，不含后加的 `#chordSound`。`OPTIONAL_ELS` 把它列为可选元素、事件绑定走可选链，否则 `assertEls()` 会在分享页启动阶段抛错导致白屏。
- 桌面端 `electron/preferences.js` 与 Android `PreferenceRules.java` 的设置同步白名单加入 `chordSound`；录制页导出的离线音轨改用 `core.hitSoundKind()` 给出的 `kind` 取音，同押仍只出一发（`a` 字段保留恒为 0 以兼容旧合成脚本）。

## 四、验证与发布

- `tools/check.sh --full`：217 项 Node 测试 + 2 项附加检查 + 32 项端到端冒烟全过；新增 `tools/test_sfx_controls.mjs`（分享页可选元素、默认勾选与 title 一致性）与 `tools/test_sfx_styles.mjs`（每档音色确实不同、限幅链静态无压缩器）。
- 线上增量部署只替换入口页、分享页资源别名与 3 个前端文件（`sfx.js` / `app-audio.js` / `app-wiring.js`），曲库与其它带哈希资源未动；部署后核对旧别名与「拍手」文案残留均为 0。
- 本版仅发布源码包，客户端安装包（Windows / macOS / Linux / Android）与曲库包维持 v0.7.1。
