# v0.6.26 · 曲库核对与构建可靠性

线上曲库更新为 2,549 首曲目、7,645 张谱面。补入已核实的新曲包，并完成 83 个曲包的作者资料修正；封面全部可读。沿用 0.6.25 的横向节奏轴和资源管理修复。

静态构建改为核对 ZIP 成员内容与转换参数。只改署名时复用音源和封面，调整缩略图尺寸、质量或编码器时自动重建对应资源。缺封面、封面解码失败、缺等级、难度间曲名或作者冲突会阻止发布。

旧哈希资源清理默认仅预览；清理保留至少三代及最近七天的引用，首次接管的旧资源也有宽限期。录制源指纹和时间轴核验成为可独立测试的模块，录制断点需匹配曲包、渲染器和参数；前端与录制工具共用版本资料。

79 项真实界面检查、完整发布检查和全库 40,810 项资源核验通过。本机未安装 PHP，PHP 冒烟检查由 GitHub CI 执行。六份桌面附件为不带曲库的轻量包，首次运行请选择自己的 `site/`。此版未重新制作全量桌面包；0.6.25 全量包仍保留在既有网盘目录。

[在线查看器](https://ub.thregren.world/) · [源码与构建说明](https://github.com/Thregren/jubeat-chart-viewer)

附带的 `jubeat-site-update-0.6.26.tar.gz` 是针对 0.6.25 在线站点的公开资源增量部署包，配套 JSON 提供逐文件 SHA-256；它不是独立完整曲库安装包。
