# v0.6.23 · 首 marker 起始位置提示

播放器新增“首 marker 提示”开关。开启后，从音乐 0 秒起标出第一批音符的位置：使用与同押边框一致的圆角粗角框，格子中央分两行显示“这里 / 开始”。首批为同押时全部标出；长押仅标起点。

提示在对应 marker 接近动画出现前淡出，避免遮挡正式动画。暂停、拖动、切难度和调整速度时按当前时间重建提示；开关会保存。默认关闭。

录制页面支持同样的提示，显示时钟与谱面时钟分开处理，原音频和打点声的位置不变。音乐零秒已出现 marker 的谱面不叠加起始提示。

验证覆盖首批单音及 2 / 4 / 16 同押、长押起点、长前奏、淡出边界、正负起点偏移、倒序拖动、开关与逐帧录制时钟；完整发布检查通过。

[在线网站](https://ub.thregren.world/) 刷新后可使用新版。六份轻量桌面包不含曲库、音乐、封面和 Marker 素材；桌面端请从本版本源码重建自己的 site 目录，再由桌面程序打开。
