# v0.7.0

本版优化谱面查看、移动端布局和曲库操作，并提供全平台轻量客户端。

- 音符序号默认随 Marker 出现；可开启「Perfect 帧时显示」恢复原有时机。Perfect 帧后的停留时间略微缩短，同押高亮保持完整周期。
- 长押箭头在命中前以贴底的半尺寸显示，在 Perfect 帧开始平滑放大并移动。
- 优化不同尺寸下的 4×4 面板比例、歌曲信息与封面对齐，以及移动端节奏轴和物量条的布局。
- 精简曲库侧栏，优化搜索、版本筛选和歌曲列表；重置可清除搜索与筛选并退出 7 日热门。歌曲列表中按空格控制谱面播放和暂停。
- 修复 iPhone Safari 聚焦搜索时的意外放大；搜索框增加清除按钮。背景故事每次打开都从开头显示，移动端关闭侧栏时同步收起「关于」。
- 移除「彩虹猫 Nyan」按键音效；桌面端和 Android 均可保存音符序号显示时机设置。

## 下载和使用

Windows、macOS、Linux 均提供 x64 与 ARM64 轻量包，Android 提供 APK。安装包**不包含曲库**，请从[夸克网盘](https://pan.quark.cn/s/e9c12157e039)下载 `jubeat-library-0.6.50.zip`，在桌面客户端或 Android 中导入。也可以直接[在线使用](https://ub.thregren.world/)。

Android APK 与 v0.6.50 使用相同签名，可覆盖升级。macOS 程序未经商业签名，首次打开可在 Finder 中右键选择「打开」。Windows 构建未经签名；Linux AppImage 需要执行权限。

附件包含各平台安装包和 SHA-256 校验文件。已验证安装包结构、Android 签名与版本、关键功能和桌面／手机浏览器；没有逐一在所有目标操作系统和真机上启动测试。
