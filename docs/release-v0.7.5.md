# v0.7.5 · 缓存隔离、异步设置与发布恢复

本版基于 v0.7.4，保留已有变速和定位同步修复。

**仅源码发布**：只提供 GitHub 自动生成的 Source code ZIP / tar.gz，不附加安装包、曲库或站点资源包。已有客户端不会自动获得本版源码修复。

## 改进

- 谱面解析由公共核心的 WeakMap 缓存统一负责。复用时间映射，重新加载时克隆可变音符状态；编号选项变化时重新编号，避免旧渲染状态和旧编号污染缓存。
- 24 MiB 谱面缓存同时估算解析后音符占用，减少密集谱面驻留内存。
- 桌面设置只在启动时同步读取一次内存快照；写入使用异步 IPC 和串行异步落盘，错误不泄漏文件路径，前端提示保存失败，退出前等待写入结束。保留主框架同源校验、键白名单及大小限制。
- 本地 HTTP 不再提供重建索引操作。清单验证可运行 `JUBEAT_LIBRARY=/path/to/library python3 tools/reindex_library.py`；重启开发服务后重新载入内存索引。
- 预览服务限制并发连接，拒绝目录列表、隐藏文件和越界软链接，保留音源 Range 请求。
- 构建发布写入恢复日志。进程中断后，下次构建恢复旧文件；恢复前拒绝打包。保留最新版本的前端入口与分享页同步和硬链接增量优化。
- 缩略图版本探测增加超时；Electron 固定为 44.11.3，打包依赖中的 minimatch 固定为 11.0.8，保留本地 sprintf 安全补丁。
- 访客数据库升级时，先转换上海日期再计算当日范围，修复 UTC 16:00 后的跨日计数初始化；保留累计计数。
- 合成浏览器曲库补齐空的可选背景资料清单，主题回归不再因缺少测试资源而失败。
- 浏览器回归使用当前版本图选界面与筛选栏；线上验收检查允许现有的匿名谱面加载计数，继续拒绝非约定字段。
