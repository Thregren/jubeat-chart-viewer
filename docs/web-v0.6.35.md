# 网页版 v0.6.35

节奏轴支持独立的网格起点。音乐魔方 21 首加入按现有音频与谱面估计的起点校准信息，其中两首维持零偏移。校准只移动拍线和拍数标签，不修改音频、音符时刻、音频 offset 或录制时钟；拖动定位继续使用原谱面时间。

校准状态在节奏轴提示中标为估计值，尚未核对官方小节起点和拍号；视频抄谱的测量抖动及合法细分不做吸附或舍入。没有校准信息的旧曲库保持原有行为。

曲库在谱面 meta 中使用可选字段 `rhythm_grid`：`version: 1`、`origin_chart_seconds`（相对原谱面时钟，有限数值，范围 -60 至 60 秒）及 `status: "estimated"`。未知版本或无效数值被忽略。新增字段随目录曲库压缩和导入保留；需要新版前端才能显示校准网格。

优先更新网页版，轻量客户端稳定版仍为 v0.6.30。
