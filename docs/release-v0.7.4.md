# v0.7.4 · 变速与定位同步修复

本版修复反复切换播放速度、拖动物量条后音乐与 Marker 错位，以及慢速保音调播放时 Marker 延后的问题。

**仅源码发布**：GitHub 自动生成的 Source code ZIP / tar.gz 是本版唯一下载；不提供安装包、曲库或网站资源包。已有 v0.7.1 客户端不会自动包含本版修复。

## 修复内容

- 切速时清除旧插值锚点，以媒体元素最新播放头重新锚定，避免旧倍率外推残留。
- 画面时间回退时重建音符及连击状态；音乐原始时间回退时清除已排队的旧打点音并重新定位。
- 播放中的 Marker、长押和打点音采用实际生效的播放倍率；暂停预览和录制保留选择倍率。
- 原生媒体不再使用未承载音乐的 AudioContext 输出延迟，保留 `?outms=毫秒` 的显式设备校准。
- 桌面 Chromium 129+ 保音调播放按浏览器 WSOLA 窗口修正约 25ms 源时间的呈现映射；实际 seek 位置不加修正。`?wsolaclock=0` 可用于排查浏览器实现变化。其他浏览器、移动设备和暂停/seek/拖动预览不套用此兼容修正。

## 验证

- 229 项 Node 测试通过；`tools/check.sh --full` 的已执行检查通过，包括默认及强制原生后端各 50 轮真实浏览器交错操作。没有现成 `./site`，已有站点完整性检查跳过。
- macOS 27.3 / Edge 153 实际回录：WAV 与带和弦背景的 Opus 各进行 50 轮变速和拖动，操作后不额外 pause/seek，每档观测 24 秒。
- 操作后绝对误差 P95：0.5× WAV 30.1ms、Opus 29.5ms；0.75× WAV 26.0ms、Opus 21.0ms。各倍率操作前后中位数变化小于 20ms；回录脉冲频谱检查保音调通过。
- 验收针对本机系统音频与窗口帧，不等同外部声光测量；尚未验证 iOS、Android、Safari、Firefox 或其他输出设备。

详细方法、完整数据和限制见 [测试报告](testing/speed-seek-sync.md)，复现方法见 [回录工具说明](../tools/avsync/README.md)。
