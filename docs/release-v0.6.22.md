# v0.6.22 · 变速保音调、Marker 常速设置保存与播放体验优化

「Marker 保持常速」现在会记住上次选择，刷新或重新打开页面后仍保留开启或关闭的状态。首次使用默认开启；开启后接近与命中动画维持 1× 时长，音符落点仍随歌曲速度同步。

## 播放体验

- 播放速度支持 **0.25–2.00×**，每档 **0.05×**，包含 0.75、0.80、0.85、0.90、0.95。
- 变速默认保持原音调；复用已下载的音频，不重复下载整首歌。
- 播放完成后暂停并回到歌曲开头；整首循环和 A–B 循环照常使用。
- 桌面端物量条拖动按正确图形坐标实时预览，松手后提交一次音频跳转。
- 包含此前安卓端轻点曲库入口和选曲交互修复。

## 性能与鲁棒性

- 换歌、切难度与刷新会取消过期请求，防止旧结果覆盖当前选择；切换速度不再造成时间跳位。
- Marker 图片最多 6 路下载，缓存按最近使用顺序回收，并保护当前设计。
- 构建先在临时目录完成，失败保留原站点，发布失败可回滚。内容哈希资源支持长期缓存，索引在资源之后更新。
- PHP 入口限制公开文件及路径，HEAD 不读取正文，错误响应不缓存。
- 桌面运行时更新为 Electron **44.6.0**。

## 网站与曲库

[在线网站](https://ub.thregren.world/) 已同步 **2,269 首歌曲 / 6,797 张谱面**。本次 Release 附件不含音乐、封面或 Marker 素材；更新桌面版时仍需指向自己的 `site/`，并从此版本源码重新构建站点以使用新的播放功能。

## 升级与附件

刷新网站即可加载新版本。既有 Marker 设计、音量和序号设置保留。Marker 常速设置从本版开始保存。

六份轻量桌面包分别对应 Windows x64 / arm64、macOS x64 / arm64、Linux x86_64 / arm64。附件结构和 SHA-256 校验和见 [manifest](https://github.com/Thregren/jubeat-chart-viewer/blob/v0.6.22/docs/release-v0.6.22.manifest.json) 与 [sha256](https://github.com/Thregren/jubeat-chart-viewer/blob/v0.6.22/docs/release-v0.6.22.sha256) 文件。
