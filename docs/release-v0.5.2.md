这一版是三块：安全/健壮性加固（对照第三方审查报告逐条过了一遍）、接入 Cloudflare CDN 之后
暴露出来的几个问题、以及一堆界面上「浪费高度 / 说了算不直观」的小修。桌面端跑法没变。

## 安全与健壮性

对照一份只读安全审查报告逐条核过（其中「文件名注入 code/level」那条实际打不到：
`library.py` 用的是 `_([A-Z]{3})\s*Lv([0-9.]+)` 严格解析，code 只可能是三个字母），该修的修了：

- **干掉全部 9 处 `innerHTML` 赋值**：曲目列表骨架、难度按钮、16 个面板键、下拉项、清空操作，
  一律改成 DOM + `textContent` / `replaceChildren()`
- **公网 JSON 不再泄露本机信息**：`data/library.json` 去掉了 `library` 绝对路径，
  `data/markers.json` 去掉了 `generated_by` / `root`；开发服务器的接口同样处理
- **构建产物加 `robots.txt`**（Disallow `/media/` `/data/` `/markers/`），并纳入 `--prune` 清单
- `sfx.js` 补上 `?v=` 版本号（之前漏了，会被 12 小时缓存卡住）
- `deploy/` 里新增安全头 snippet 与加固后的 nginx 示例：CSP、nosniff、Referrer-Policy、
  X-Frame-Options、Permissions-Policy、X-Robots-Tag、限流与并发限制、防盗链、目录 403→404

## Cloudflare CDN 接进来之后

- **修正限流口径**：源站日志和 `limit_req` 原本都按 CF 边缘 IP 算（162.159.x.x），
  等于所有走同一个边缘的用户共用一个桶，音频那个 `4r/s burst=20` 很容易误伤。
  新增 `deploy/cloudflare-realip.conf`（CF 官方 IP 段 + `CF-Connecting-IP`），
  现在按真实访客 IP 算
- **版本自检节流到 60 秒一次**：它用的是 `cache:no-store` + 唯一 query，会穿透 CDN 直达源站，
  以前每次页面加载 + 每次切回前台都打一次
- `/data/*.json` 的响应头改成允许 CDN 缓存 30 秒（浏览器仍每次校验 → 改谱立即生效）；
  CF 默认按扩展名缓存、`.json` 不在列表里，还需要在面板加一条 Cache Rule，步骤写在 `deploy/README.md`
- 顺带发现：命令行 `curl`（LibreSSL）会被 CF 重置 TLS 握手，测这个站得用真实浏览器

## 界面 / 布局

- **iPad 竖屏用不上全高**：窄屏 `#app` 写的是两行网格，但侧栏是 `fixed` 不占格，
  `.stage` 落在 `auto` 行、空的 `1fr` 行把剩余高度全留在底部；另外 `fitPanel()` 把窄屏面板
  死限在 430px。现在改成单行网格，上限 720（桌面 460 → 560）
- **加载进度改成浮层（pop）**：原先是流内元素，出现/消失会把下面顶来顶去、整页高度一直变
- **音源没就绪时播放按钮禁用**：以前允许点、点完排队到数据到齐自动播，但那时谱面状态可能还没落好，
  听起来就是「提前响了、不对拍」；整套排队逻辑删掉，键盘（空格）走同一个判断
- **选项措辞改直观**：速度→播放速度、偏移→声画偏移、marker→按键动画、PERFECT 帧→动画对齐帧、
  判定特效→命中特效、marker 顺序数字→音符序号、同押光晕→同押高亮、打点音→按键音效……

## 顺序数字

- 从「按整秒切」改成**按换气切句**：空档明显比周围稀疏（≥ 最近 8 个空档中位数的 1.25 倍，
  且不低于 0.5 拍）就重新从 1 数；参数是在全库 4099 份谱面上扫出来的
- **上限 9**，保证数字是个位（密集谱面里光调阈值降不下两位数占比：间隔是量化的 0.5/0.75 拍，
  倍数 1.05~1.25 触发的是同一批断点）
- 这三个参数（序号断句 / 最小换气 / 序号上限）都**开放到选项区**，改完立刻重编，设置会记住

## 音效

- 新增一组按键音效 **「比利·海灵顿」**：重音拍用 `billy-accent`，其他拍用 `billy-normal`
  （和太鼓 don/ka 一个套路）；素材没放时回落到一声点击，不会哑掉
- **太鼓「咚/咔」换成真素材**：起音 2ms、裁掉了多余的尾部静音（ka 原本只有 78ms 敲击却挂了 242ms 空白）
- 素材一律保留 **WAV** 而不是转 ogg/mp3：mp3/aac 编码会引入约 26ms 前置延迟（「慢一拍」的来源），
  ogg 在 Safari 上解不了会静默回落合成音；WAV 两端都能精确解码，文件也只有几十 KB
- 取素材的 URL 带上 `?v=<前端版本>`：素材改了但文件名不变时，不会被浏览器/CDN 的 7 天缓存卡住

## 部署 / 更新

Release 附件仍是**不带曲库**的桌面版（每个约 100 MB）：解压直接运行，首次启动用菜单
「文件 → 选择站点目录（site/）」指向自己构建的 `site/`（会记住）。

服务器上更新前端只要传这几个文件，曲库一个字都不用重传：

```
铺面查看器/player/static/index.html   →  <站点根>/index.html
铺面查看器/player/static/app.js       →  <站点根>/static/app.js
铺面查看器/player/static/style.css    →  <站点根>/static/style.css
铺面查看器/player/static/sfx.js       →  <站点根>/static/sfx.js
```

**记得同时改 `index.html` 里的 `?v=`**（只要和之前用过的都不同就行，不必等于 app 版本号），
否则浏览器会继续用缓存里的旧文件。接了 CDN 的话，`deploy/README.md` 里有 real_ip 与
Cache Rule 的配置说明。
