# 网页版 v0.6.31

- 左侧长押筛选旁新增「图选 Marker」，将下方列表切换为带截图和名称的卡片；支持按名称、中文名、日文名和编号搜索。点击后与原 Marker 下拉框同步，原选择入口保留。点击「返回选歌」恢复歌曲的搜索、筛选和滚动位置。
- 虚拟歌曲列表统一控制封面加载，移除双重懒加载；缩略图失败后尝试原图，并有限重试，回收行时取消重试，避免快速滚动后永久丢图。
- 序号字号、序号透明度、光晕透明度改为常用档位下拉框。既有非标准数值作为「原设置」选项保留，避免改变用户偏好。
- 设置标签与控件并排，减少分组留白，手机保持双列，兼容 320px 窄屏。

本次优先更新网页版，不发布新的安装包。现有轻量客户端稳定版仍为 v0.6.30，独立 v0.6.29 曲库包继续适用。
