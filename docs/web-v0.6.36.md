# 网页版 v0.6.36

此版本的分享页加载方式与线上严格 CSP 不兼容，已由 [v0.6.37](web-v0.6.37.md) 修复；请使用新版本。

歌曲信息右上角新增「分享」。支持时调用系统分享，否则复制链接；权限不允许时显示可手动复制的链接。链接包含歌曲和当前难度，不包含进度、速度或录制参数；接收者打开后从头开始，默认暂停。

静态分享页在初始 HTML 中提供歌曲标题、描述、专辑封面和 Open Graph 信息，无需运行 JavaScript 即可抓取。正常浏览时保留该页面地址并加载当前版本的查看器。现有根路径 `?song=...&chart=...` 仍可使用，旧自动化链接的 `t` 参数保留兼容；新分享页会忽略进度和自动播放参数。

桌面/安卓的本机地址会转换为公开站点的分享地址，避免分享 localhost 端口。仅本地存在的曲目仍需要接收者拥有相应曲库，不能通过链接上传歌曲。

微信：本次已提供可抓取的标题和小封面，但站点未配置公众号与 JS-SDK 签名服务，也未在真实微信会话中发送测试。不能保证每个微信客户端都显示自定义缩略图；后续账号配置完成后才可继续接入、实测微信内转发卡片。

## 部署

`tools/build_share_pages.py --library SITE --out SITE --base-url https://ub.thregren.world/ --version 0.6.36` 从显式曲库索引生成 `share/`，包含每首歌曲的预览 HTML 和小图。安装 Pillow 时生成最大 300px 的 JPEG；无 Pillow 时使用已存在的封面 URL。无需 PHP 或数据库。目录构建、压缩构建及公共包已纳入分享资源。自托管子路径请在部署时传入对应 `--base-url`。

分享页由 `share-entry.js` 加载当前入口，避免旧分享链接固定在旧前端版本；标题与封面仍保留在最初的 HTML。曲库新增/删除或标题、封面变化时应重新运行生成工具。缺失封面使用站点图标，不伪造专辑图片。

验证包含参数过滤、中文及特殊字符、图片大小、路径越界、HTML 转义、静态元数据、从头定位、分享回退和录制隐藏。轻量客户端稳定版仍为 v0.6.30。
