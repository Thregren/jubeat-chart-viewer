# jubeat 官方 marker 一览

marker（マーカー）= 音符落下时面板上出现的「絵柄」，也就是玩家常说的音符皮肤。KONAMI 官方 HOW TO 的原文是「音楽に合わせてパネルに絵柄(マーカー)が出るのでタイミングよくタッチしましょう」。

注意：KONAMI **没有**发布过可直接下载的 marker 素材包。最权威的 marker 列表就是游戏内 OPTION → マーカー选择画面；下面的清单与缩略图来自对该画面的整理（RemyWiki / jubeat@Wiki / BEMANIWiki 三方对照）。

共 52 条记录，按首次登场版本排列。Stealth 在 ripples / knit / copious / saucer / Qubell 各版本都有不同图案；Himouto! Umaru-chan 与 NEW GAME! 已分别于 2019-06-24、2020-07-27 下架。

## 想要“会动的” marker 素材

- 游戏内实拍/录屏是唯一 100% 准确来源；选择画面里可以直接预览每个 marker 的动画。
- 社区工具 jubeat analyser 的 marker 包（img/markers/ + markerlist.txt）是流传最广的拆包素材整理；格式说明见 https://mobiuslau.github.io/jubeat/analyser/markers/
- 开源模拟器里也有可用的 marker 目录，例如 https://github.com/Stepland/jujube/tree/master/assets/markers （marker.json 定义帧与判定动画）。
