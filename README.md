# jubeat 谱面确认

在网页或离线客户端里浏览 jubeat 谱面，用 4×4 面板和逐帧 Marker 核对节奏、同押与长押，适合看谱、练谱和制作谱面确认视频。

**[在线使用](https://ub.thregren.world/)** · **[下载轻量客户端](https://github.com/Thregren/jubeat-chart-viewer/releases/tag/v0.7.1)** · **[完整曲库与客户端网盘下载](https://pan.quark.cn/s/e9c12157e039)**

## 主要功能

- **找谱和看谱**：搜索曲名或艺术家，按版本、谱面类型和难度筛选排序；版本支持带 Logo 的图选和搜索；支持 7 日热门、搜索清除和一键重置，曲目列表按需渲染。
- **Marker 与提示**：官方逐帧动画、单列图选、首 Marker「这里／开始」提示、同押面板框与双色高亮。
- **界面主题**：切换 13 套按各版本特色重新设计的配色与图案，包括星空、涟漪、城市、热带植物、木纹和砖墙，4×4 面板和边框也会随主题变色；记住上次选择。
- **节奏可视化**：音符顺序数字默认随 Marker 提前显示，也可设置为 Perfect 帧时显示；支持断句和节奏分组配色、长押轨迹、总连击、物量条和可细分的横向节奏轴。
- **反复练习**：0.25×–2× 保持音调变速、声画偏移、A–B 段落循环、循环播放；按键音有「点击」「太鼓」两组，各分普通、16 分及更密、同押三档，「同押独立音效」默认开启。
- **试听和分享**：独立原试听循环；歌曲分享页打开后自动定位歌曲和难度。
- **手机与离线**：手机曲库抽屉（图选 Marker 后自动收起）、折叠设置、PWA 安装；桌面与 Android 客户端导入完整资源包后离线使用。
- **关于与友链**：在侧栏「关于」查看项目 GitHub、Beyond ↑ JUBEAT ♪~ 友链，以及线上历史和今日访客数。

离线使用：

1. 下载适合平台的轻量程序，以及网盘中的 `jubeat-library-0.6.50.zip`。该独立曲库包包含 **2469 个歌曲／谱面版本条目、7373 张谱面**，并带有歌曲背景故事资料，可导入新版客户端。[v0.6.50 Release](https://github.com/Thregren/jubeat-chart-viewer/releases/tag/v0.6.50) 中的 `web-0.6.50.partNNN.zip` 是网站部署用的独立分卷，不能拼接成完整曲库，也不能直接导入客户端。
2. 桌面端将整个曲库 ZIP 拖进窗口，或从文件菜单导入；Android 安装 APK 后选择「导入资源包」，导入同一个 ZIP。
3. 校验并导入后即可离线看谱和播放。程序与曲库可分别更新；导入期间需要容纳旧库和新库。

macOS 程序未做商业签名，首次打开可在 Finder 中右键「打开」；Linux AppImage 需要执行权限。轻量程序自身不包含歌曲、封面和试听。

更多安装方法见 [客户端与压缩曲库](docs/压缩曲库与客户端.md)，曲库范围和按版本安装见 [目录曲库说明](docs/目录曲库.md)。

## 最近更新

**v0.7.4 · 变速与定位同步修复**

- 修复播放时反复变速、拖动物量条后，音乐与 Marker 逐渐错位；切速立即采用最新媒体播放头，定位或时间回退时重建画面状态并重排打点音。
- 修复慢速保音调播放下 Marker 延后的问题：桌面 Chromium 129+ 对保音调处理窗口作源时间映射，暂停、拖动、seek 和强制录制不额外偏移。原生媒体不再套用不承载音乐的 AudioContext 延迟；仍可通过 `?outms=毫秒` 按设备手动校准。
- Marker、长押与按键音采用实际播放倍率。保留偏移设置、音调保持和暂停拖动后的播放意图。
- macOS / Edge 系统音频与独立窗口回录：WAV、带和弦背景的 Opus 各交错操作 50 轮；0.5× 操作后 P95 为 30.1 / 29.5ms，0.75× 为 26.0 / 21.0ms，同倍率前后中位数变化均小于 20ms。此结果限本机回录，尚未覆盖移动端及其他浏览器。
- 新增播放器状态回归、浏览器真实拖动回归和可复现的音画回录工具；[完整测试报告](docs/testing/speed-seek-sync.md)列出方法、逐阶段结果及限制，[回录说明](tools/avsync/README.md)列出依赖与执行步骤。

**这是仅源码发布**，不含客户端安装包或曲库；v0.7.1 客户端不会因网站更新而自动获得此修复。详见 [v0.7.4 发布说明](docs/release-v0.7.4.md)。

## 主要架构

```mermaid
flowchart LR
    A[显式目录曲库] --> B[构建与资源校验]
    B --> C[静态索引、谱面、音频与图集]
    C --> D[网页浏览器]
    C --> E[Electron / Android 离线客户端]
    D --> F[可选 PHP + SQLite 访客统计]
```

构建期将本地 WAV 母库转为 Opus 精简目录，并生成内容哈希索引、无损 Marker 图集和歌曲分享页。运行期只读取明确列出的资源，不扫描其他曲库。

前端由曲库、音频、渲染和设置服务管理生命周期。正常播放优先使用 WebAudio；保音调变速和超预算音源使用原生媒体管线。Marker 跟随音频时钟绘制，辅助时间文字最多每秒更新十次，暂停时停止绘制。画质可选「自动／清晰／省电」，录制保留完整精度。

主查看器可纯静态部署。可选的访客统计使用 PHP + SQLite；页面“关于”中显示历史及今日访客数，IP、歌曲访问与 UA 明细保存在禁止公开访问的目录，详见 [统计部署说明](deploy/visitors/README.md)。
