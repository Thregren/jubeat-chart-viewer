# v0.6.44

本版重新设计谱面查看器的 13 套界面主题，并更新桌面和手机截图。

- 按版本区分主色、明暗和图形：包括 ripples 涟漪、knit 编织线、copious 深蓝星空、saucer 与 saucer fulfill 的黑白界面、clan 四街区色、festo 热带色彩、Ave. 木纹和 beyond the Ave. 砖墙。
- 「音乐魔方」主题移至列表末尾，兼容已保存的主题设置；浅色主题的控件、歌曲选中状态和文字对比度同步调整。
- 包含 v0.6.43 的 Marker、音频加载、访客统计和资源管理修复，详见 [网页版更新说明](https://github.com/Thregren/jubeat-chart-viewer/blob/master/docs/web-v0.6.43.md)。

提供 Windows、macOS、Linux 的 x64/ARM64 六份轻量客户端和 Android APK。安装包不包含曲库；可从 [夸克网盘](https://pan.quark.cn/s/e9c12157e039) 获取现有的独立完整曲库并导入。Android APK 与上一发布版使用相同签名，可覆盖升级。

已检查桌面与手机浏览器的 13 个主题、主题切换和保存、录制模式、播放和分享页；仓库自动测试通过。轻量包经过结构、版本及 SHA-256 校验；未逐一在所有目标系统和真机启动测试。macOS 程序未做商业签名。
