# 开放目录曲库使用说明（v0.6.28 起）

新版网页的默认输入是 `jubeat-directory-v1`：独立 JSON 谱面、WAV 完整音频、WAV 原试听、PNG 封面。不需要 MCZ，也不扫描旧曲库、旧索引缓存或 `official_levels.json`。曲名、作曲、等级、资源缺失和版本归属都从指定的本地统一库读取。可在构建前用解包工具的离线核对流程，按网页既有版本名整理目录，并在谱面匹配后补充曲名/等级；网页封面、音频和谱面不会替换本地资源。

## 直接使用按版本包

1. 建立一个空目录，解压 `00_浏览器公共文件.zip`。
2. 将同一批次的任意版本 ZIP 解压到同一个目录，合并 `data/` 和 `songs/`。不要额外套一层 ZIP 文件名目录。
3. 使用 Python 3.10+ 执行 `python3 启动查看器.py`，打开提示的本机地址。默认端口 8124；`--port 8125` 可修改端口。
4. 搜索或筛选版本，选歌、选难度。播放控制行最右侧的「试听」只在存在原试听时显示，使用独立的 `preview.wav` 循环播放；再点停止。试听与正曲互相暂停。原界面布局和样式保持不变，不新增下载按钮或素材面板。

公共包含前端、按键动画、启动程序和顶层索引；版本包含该版本新增/改谱条目、该版本索引及来源索引。未安装版本的索引返回 404 时会跳过；已安装索引损坏则明确报错。页面不会到其他曲库寻找替代资源。

新版批次应在新空目录安装，并同时更新公共包与所需版本包。不同批次的清单可能变化，混合解压会留下不再被引用的文件。双击 HTML 的 `file://` 模式不支持索引请求，必须通过 HTTP 服务打开。

## 从本地统一库生成

先使用 [jubeat-extract-tools 的浏览器导出流程](https://github.com/Thregren/jubeat-extract-tools/blob/main/docs/browser-library.md)：

```bash
# 在解包工具仓库根执行。只读取已经完成的本地统一库。
python3 -m workflows.browser_library --library input/unified --output output/browser \
  --archives output/version-zips --verify-zips
```

然后在本查看器仓库根执行：

```bash
python3 tools/build_site.py --library ../output/browser
python3 tools/serve.py ../output/browser --port 8124

# 生成与版本包配套的公共文件包，同时给目录安装可搬运的启动脚本：
python3 tools/package_directory.py --library ../output/browser \
  --output ../output/version-zips/00_浏览器公共文件.zip
```

`--library` 必须显式指定。默认在原导出目录补齐前端；可用 `--out site` 生成另一份站点。在同一文件系统中媒体会尽量硬链接，跨盘复制；WAV 不进行转码，不需要 ffmpeg。前端总是复制，更新代码后需重新构建、刷新页面。

可选的 Python 动态服务也支持目录曲库：

```bash
JUBEAT_LIBRARY=../output/browser python3 铺面查看器/player/server.py
```

动态服务按声明路径发送 WAV/PNG/JSON，支持 HTTP Range。目录模式不读旧 MCZ、旧缓存或旧等级表。环境变量路径错误时直接报错，不会静默切换到别的库。默认仅查找项目内 `directory-library/data/library.json`。

旧 MCZ 转站工具保留为显式兼容入口：`JUBEAT_LIBRARY=input/synthetic-or-legacy python3 tools/build_site.py --legacy-mcz --out site`。它不属于本地统一库流程，本次统一库的生成、构建和运行均不调用该入口。

## 目录和字段

```text
browser/
  index.html
  static/                         网页代码
  markers/                        查看器按键动画（不是歌曲库）
  data/library.json               顶层清单，列出 versionIndexes
  data/versions/<version>.json     每个版本的歌曲索引
  data/sources/<version>.json      统一库保留的完整来源对应关系
  data/export.json                条目、谱面、素材数量
  data/build.json                 前端构建结果
  songs/<version>/<category>/<identity>/
    song.json                     此条目的元数据、缺失标记和资源路径
    provenance.json               原始来源证据
    bgm.wav                       完整音频（若有）
    preview.wav                   原游戏独立试听（若有）
    cover.png                     封面（若有）
    charts/BSC.json               兼容播放器的开放 JSON
    charts/BSC.events.json        精确事件，保留源 tick_hz
    original/BSC.eve 或 BSC.seq    原始谱面
```

主清单声明 `format: "jubeat-directory-v1"`、`songs: []`、`versions: []` 和 `versionIndexes`。每个版本索引也声明相同格式，内含 `songs` 数组。歌曲字段如下：

| 字段 | 含义 |
|---|---|
| `id` | 稳定相对目录标识，含版本、首次收录/谱面变化分类、歌曲身份 |
| `title` / `titleKnown` | 未知曲名显示原 ID，标志为 false，仅经离线谱面核对后补充网页元数据 |
| `version` / `source` / `identity` | 统一库归档版本、具体来源、去重身份 |
| `charts` | 实际存在的难度；不创建缺失难度，空数组仅适用于仅资源条目 |
| `charts[].level` / `levelKnown` | 缺失等级为空，显示「等级未知」或 `?`，不当作 0 级 |
| `charts[].notes` / `heads` / `holds` | 连击口径为头数加长押数；长押头尾各一次判定 |
| `assets.audio` / `preview` / `cover` / `thumb` | 明确的相对 WAV/PNG 路径；没有就不声明 |
| `assets["chart:BSC"]` / `assets["exact:BSC"]` | 兼容谱面和精确事件文件路径，ADV/EXT 同理 |
| `missing` | 如 `bgm`、`preview`、`cover`、`chart:BSC`，如实展示 |
| `resourceOnly` | 没有可玩谱面，只浏览/下载现存资源及播放原试听 |

路径只允许站内相对路径，不接受绝对路径、协议、反斜线或 `..`。动态服务只发送索引声明的歌曲资源。新增自定义资源时也应遵守该格式。

`*.json` 谱面沿用现有播放器可解析的 MC 数据结构（`meta/time/note/extra`），改为直接 JSON 文件，不再套 MCZ 容器。它是兼容播放表示；现有归一化中的拍点换算有量化。`*.events.json` 保留源事件 tick 与原始时间精度（原游戏通常为 300Hz；音乐魔方视频抄谱使用其自身 tick_hz，数值精度不等于视频观测准确度），用于精确研究/后续播放引擎，不应声称当前网页已直接使用该 tick 文件。原始 EVE/SEQ 同时保留。

## 版本范围、去重与缺失

导出支持已经由归一化流程完成的街机 jubeat、ripples、knit、copious APPEND、saucer、saucer fulfill、prop、Qubell、clan、T44/JAEPO、festo（官方与 Omnimix 分开）、Ave.、beyond the Ave.、jubeat plus、jukebeat。这是源数据适配范围，不表示已验证这些产品的所有历史更新。

本批原始归档有 18 个来源目录；按网页既有版本体系整理后有 17 个版本分类（含音乐魔方）。共 2,457 个条目：2,457 个有可玩谱面，原 209 个特殊资源条目已按分类移除；7,329 份谱面、2,456 份完整 WAV、2,435 份原试听 WAV、2,454 份 PNG。音乐魔方单独收录 21 首 EXT，保留本地视频复核抄谱和原始来源说明。原 209 个条目（208 个只有完整音频，1 个只有图片）已从当前目录和版本包中移除。具体缺失以每条的 `missing` 为准。

沿用统一库的去重：最早街机版本优先，移动版补充；只有可玩音符/时序变化才另存，纯 HAKU/MEASURE 引导变化不另存。版本包包含首次归档条目或改谱条目，不等于该版本发行时的全部歌曲；「归档最早来源」也不必等于游戏实际首次上线日期。T44、合并版本、jukebeat 等零新增来源仍有来源索引，不复制已经归属其他版本的歌曲。

WAV 继承统一库的 PCM24、原采样率和声道，不再次有损转换。原试听必须来自独立试听资源，不从完整音频截取。PNG 使用统一库已修正颜色的封面；未提供封面时显示占位。没有 BGM 的谱面仍可静态查看，播放按钮禁用，避免请求不存在的媒体。

## 校验与故障排查

每个版本 ZIP64 带 `PACKAGE.json`，记录每个文件的字节数和 SHA-256；包外 `.zip.json` 记录整包 SHA-256、大小和完整 CRC 校验状态。`打包校验.json` 汇总所有版本；公共包另有 `.zip.json`。

- 列表为空：检查是否把版本包又多套了一层目录，确保 `data/versions/*.json` 就在站点根下。
- 等级问号/曲名 ID：统一库没有可靠元数据，属于明确未知，不是加载失败。
- 提示缺失：核对 `missing`。已声明却找不到文件属于安装不完整，构建器会报错，不能当成原始缺失。
- 试听按钮不出现：没有原试听时按钮隐藏，程序不会用正曲临时裁切代替。
- WAV 加载慢：完整 WAV 体积大；播放会显示下载/解码进度，试听使用独立短片段。浏览器必须支持该 PCM WAV。
- 修改源码后仍是旧界面：重跑构建/公共包工具，再刷新；缓存版本号由根目录 `VERSION` 统一管理。

合成测试：`python3 tools/test_directory_library.py`、`node --test tools/test_directory.mjs tools/test_runtime.mjs`。所有测试在临时目录人工造数据，不需要真实歌曲或旧曲库。

## 按网页元数据核对并加入音乐魔方

解包工具的 `workflows.web_metadata` 只缓存网页 JSON 索引对应的 JSON 谱面，不下载网页封面/缩略图、音频或试听。`workflows.curate_library` 根据所有可玩音符、长押时长和尾部方向认曲，至少匹配两个难度；只有单难度输入时以该完整难度核对。物量仅用于筛选候选，不能单凭曲名或物量认定。兼容 JSON 的比对允许整体起点平移与最多 20ms 换算误差，这只用于元数据核对，不用于删除、合并或替换本地谱面。部分难度匹配时只采纳对应难度的等级。

本批核对 2,384 条，其中 2,381 条完整匹配、3 条部分匹配；仍有 26 个可玩条目曲名未知、62 份谱面等级未知。未知项不强填。网页版本名用于分类，原始文件版本和证据继续保存在来源说明及改名映射。多个 festo / beyond the Ave. 归档可合并为相同游戏版本名，原谱和改谱条目均保留。

音乐魔方来自用户提供的独立本地目录，单独保留 21 首 EXT，包含自己的 WAV、PNG、精确事件和视频复核来源。它不是从网页复制歌曲素材，也不冒充原游戏谱面提取。未提供的 BSC/ADV 和原试听明确记为缺失，试听按钮隐藏。

详细可复现命令见解包工具仓库的 `docs/web-metadata.md`。网站运行时只读取完成核对后的目录，不再调用参考网页。

整库解析校验可用 `node tools/verify_directory.cjs output/browser output/verification.json`。它与网页共用解析器，检查全部显式路径、难度物量/长押数及精确事件结构；不需要 npm 安装依赖，不读取其他曲库或网页。

本批按用户要求删除了各版本 `特殊或不完整资源` 分类，共209组；索引、统计与分版本包同步更新。正常歌曲的缺失素材标记继续保留，音乐魔方21首EXT继续作为独立版本提供。
