# v0.6.52

本版修复连续调整播放速度后的音频错位，以及 iPad 上“背景故事”按钮不可见或触控区域过小的问题。

- 在需要保持音调的第一次变速时，媒体播放后端只交接一次；此后所有速度切换（包括切回 1×）都直接更新 `playbackRate`，不再反复更换音源、重新加载或写入播放位置。
- 每次变速后重新取样媒体时钟，避免沿用旧倍率外推时间；连续跨档切速时，音频元素、媒体时间、谱面时间和渲染时间保持连续。
- 触控设备上的播放操作区改为可换行的静态布局。“背景故事”和“分享”按钮采用 96×44px 的触控尺寸，不再与歌曲标题、难度按钮或封面重叠。
- 增加真实浏览器连续变速回归，以及桌面、手机、iPad 横竖屏和 iPad PWA standalone 的背景故事按钮与长标题弹窗布局回归。

已通过完整仓库检查、八档连续变速测试和五种视口实测。连续切速过程中媒体元素仅加载一次，交接完成后没有额外 seek；iPad 三种触控场景的按钮均为 96×44px，弹窗无左侧裁切或横向溢出。
