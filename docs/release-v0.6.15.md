# v0.6.15 · 重做打点音的「咚」

这一版只改一件事：**节拍音的「咚」重新合成**，让它在手机 / 笔记本的小喇叭上也听得清。
曲库（1479 首 / 4427 谱面）、marker、判定逻辑都没有动。

## 问题在哪

打点音里「咚」是重音拍（小节第一拍），「咔」是其他拍。老的那份 `se/don.wav` 是纯低频
闷鼓：**84% 的能量压在 120 Hz 以下**，手机和笔记本扬声器这一段基本放不出来，于是听着就
像「只有响的那几下能听见」，重音拍反而丢在音乐里。

## 怎么重做的

保留低频鼓皮（听感上还得是鼓），把中频抬起来，一共五层：

| 层 | 频率 | 作用 |
|---|---|---|
| 击打瞬态 | 2.8 kHz 带通噪声 | 小喇叭上决定「听不听得见」 |
| 鼓皮主体 | 205 → 86 Hz 下滑音 | 决定「像不像鼓」 |
| 二 / 三 / 四次谐波 | 420 / 720 / 1180 Hz 起下滑 | 中频主力，和「咔」区分开 |
| 鼓身层 | 560 Hz | 音量感，笔记本喇叭主要靠它 |
| 鼓皮噪声 + 轻度软削波 | 1.7 kHz | 补谐波，让鼓「实」 |

顺带把输出峰值压到 0.84，音量拉满也不至于顶穿。用「小喇叭模拟（450 Hz 四阶高通）+ A 计权」
量，响度从 0.0148 提到 0.0524，约 **+11 dB**；300–800 Hz 的能量占比从 1% 提到 6%，
频谱重心 670 Hz → 1556 Hz。

## 同步改了两处

1. **`static/sfx.js` 的合成回落音**（没往 `se/` 放素材时的兜底）换成同一套参数。它的衰减
   包络也重写了：原来用 `exponentialRamp` 拉一段时间会衰减得比 WAV 快，现在按时间常数
   exp(-t/τ) 打点，用 Electron 的 `OfflineAudioContext` 实渲染比对过，频谱重心和频段分布
   跟 WAV 基本一致。
2. **`tools/make_don.py`**：新增的生成脚本，`python3 tools/make_don.py` 就能重新合成
   `se/don.wav`，想再调音色改里面的参数即可（五层的频率 / 衰减都在一个函数里）。产物仍然
   不入库（`se/` 在 `.gitignore` 里），构建时复制到 `site/media/se/`。

## 升级

版本号只用来破缓存（打点音素材是带 `?v=` 拉的，不升版本浏览器会继续吃旧的 `don.wav`）。
没有新增或改动 localStorage 键，升级后设置照旧；曲库、谱面、marker 与 0.6.14 完全一致。
