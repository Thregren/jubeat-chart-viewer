# v0.7.16 · 网页版性能与稳定性修复

- 曲库滚动和搜索复用列表节点，Marker 筛选保留仍匹配的卡片。修复了启动时的重复绘制和模式切换后的绘制接管。
- 节奏轴关闭时释放谱面模型，加快超长长押的可见区间查询。物量图和能力图跳过重复绘制。
- 未知总大小的音频下载持续显示已接收字节。UB 啪系 v2、白金之星和 DIO 沿用已校准的电平。
- 背景故事正文按需加载并限制缓存大小，封面批量生成减少文字测量。访问报表改为流式汇总，播放里程碑可在统计队列释放空间后补发。
- 网页分卷保留分享页及封面，并校验内置打击音的摘要。静态预览从同一文件句柄读取 Range 响应长度和内容，避免构建替换文件时发生错位。
