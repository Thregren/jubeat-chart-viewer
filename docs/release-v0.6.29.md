# v0.6.29：本地压缩曲库与轻量客户端

改用本地统一库生成的精简资源：2457个歌曲/谱面版本条目、7329张谱面，完整音频和原试听统一为Ogg Opus 80kbps VBR，参数与旧网页一致。封面和缩略图来自本地母库，旧网页库不再作为素材来源；页面删除旧“谱面来源/曲库仓库”一行。

桌面端自带UI、不带歌曲，将独立完整曲库ZIP拖进窗口即可校验导入，也支持已解压的目录。提供Windows/macOS/Linux各两种架构。安卓版为轻量APK，通过系统文件选择器导入同一份完整曲库ZIP。完整曲库另放[夸克网盘](https://pan.quark.cn/s/e9c12157e039)的v0.6.29目录。

原试听按钮保留在播放控制行最右侧，有资源时循环播放、再点停止，缺少试听时隐藏；其余播放器界面保持原样。音乐魔方21首EXT作为独立版本保留，缺失素材和未知曲名/等级如实标记。

新增母库来源核验、Opus转码、精简打包及COS独立分卷工具；导入支持CRC、资源完整性校验和失败恢复。母库中的WAV、原始谱面、精确事件和来源继续独立保存。

使用和构建步骤见[压缩曲库与客户端](压缩曲库与客户端.md)。Release附件为轻量程序，不包含歌曲或原始游戏资源。
