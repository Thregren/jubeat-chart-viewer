# v0.6.17 · 物量口径对齐官方 + marker 序号默认右下角

这一版动的是**物量**：以前长押只数头判，物量条和 NOTE 都比实机少一截；现在按实机结算
画面那条分布图的口径重算 —— **物量 = 单点 ×1 + 长押 ×2**（头判、尾判各一颗）。
物量条本身也照官方重画了一遍（115 列 / 封顶 8 层 / 正方形格子）。另外把 marker 序号
默认挪到**格子右下角**，不再挡在 marker 动画上面。

曲库（1479 首 / 4427 谱面）、marker 素材、判定时序都没有动。

## 物量口径：单点 ×1 + 长押 ×2

对着 jubeat 官方口径的模拟器实现（jujube / Stepland 的 `Drawables::DensityGraph`）和
官方物量表（1121 首 / 3101 张谱面）逐张核过，实机口径是这四条：

| 项 | 口径 |
|---|---|
| 一颗 note | 单点算 **1**；长押**头判 + 尾判各算 1**，中间按住那段不算（合计 2） |
| 时间轴 | `max(音频时长, 最后一颗判定时刻) + 1s`（末尾那一秒是官方自己留的尾巴） |
| 分格 | **固定切 115 列**（不按曲长变列数） |
| 柱高 | 画**绝对颗数**、不按本曲峰值归一化，**封顶 8 层** |

以前只数头判，长押多的谱面会少算近一半，整首都是长押的谱面最离谱：
`袖手旁棺` 三道难度都是 18 条长押，NOTE 从 18 修到 **36**；`iris` 是 35 → **70**。
`灼熱Beach Side Bunny` EXT 从 939 修到 **1606**（272 单点 + 667 长押，其中 655 条是
1 tick 的短长押），BSC / ADV 也一起重导了。

全库物量 2,143,346 → **2,176,303**（+32,957，约 +1.54%）。用官方表核对 3101 张谱面，
现在只剩 36 张对不上，且都是**本地谱面本身和官方表不同**的曲子（如 Paranoia、
凛として咲く花の如く），和算法无关。

连击那边长押本来就是「按下 + 松开」算两下，这一版没动；这次补上的是**总 note 数**
（`library.json` 里的 `notes` 字段，物量排序和列表显示都走它）。

## 物量条照官方重做

连参数一起照抄（口径见上），不再是「每 2 秒一根柱子」那种自创画法：

- **固定 115 列**，柱高就是落在这一列的**绝对颗数**，超过 8 颗封顶在 **8 层**
- 格子**正方形**（4 px 亮面 + 1 px 暗缝，约 5 px 一格），暗金边 + 金芯
- 整张图按「条子宽 ÷ 768」等比缩放后**水平居中**（768 宽时 115 列正好 575 px，和实机一样占 75%）
- 条子高度跟着宽度走（不再写死 36 px）：桌面约 52–68 px 封顶、手机约 36 px
- 长押的**头判、尾判各画一颗**（中间那段不画），颜色和单点**完全一样**
- **播放头 / 30 秒刻度 / A–B 打点 / 点击跳转改走同一套坐标**（图的左右边界），
  否则播放头跑到两端时会和柱子错开一截；左右那两条官方式留白也接受点击，落进去贴到首尾

## marker 序号默认放右下角

「序号放右下角」这个开关**默认打开**了：数字画在格子右下角的角落标签位置，密集处不再
压在 marker 动画上。想回到格子正中，把选项区那个开关关掉即可（字号 / 透明度 / 颜色 /
光晕透明度都照旧）。

## 顺带：打点音的两处修正

0.6.16 的音频改动当时没单独发过版，一起并进这一版：

1. **同押打点音不再叠加** —— 排程是按 note 发的，4 押就会同一时刻响 4 下、音量顶穿；
   现在按「和上一发同一批」去重（阈值 1e-4s，和 `core.numberNotes()` 分同押的口径一致），
   离线录制音轨同步只出一发。
2. **「咚」的响度压回一档** —— 0.6.15 抬中频之后「咚」整体 RMS 比「咔」高 8.2 dB，
   会把咔盖掉；低频鼓皮 0.85→0.52、鼓身层 0.30→0.19、峰值归一 0.84→0.62，
   整体差收到 +4.4 dB，中频清晰度保留。

## 升级

只多了一次性设置迁移：**设置版本 8**。老浏览器里存着的「序号位置」多半是旧默认
「居中」——用户根本没挑过，所以这次只清一次这个键，让新的「右下角」默认露出来；
清完写回版本号，之后再手动关掉就不会被重置。序号字号 / 透明度 / 颜色 / 光晕透明度、
marker 设计、音量这些存档都不受影响。

版本号同时用来破缓存（前端静态资源和打点音都带 `?v=`），升级后刷新一次页面即可。
