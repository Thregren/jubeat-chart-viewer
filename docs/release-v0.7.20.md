# v0.7.20 · 数字谱小节跳转与手机布局

- 点击数字谱的小节标题、格子或节奏行，播放进度会跳到该小节开头。面板底部的 ← 和 → 用于切换相邻小节，跳转时保留播放或暂停状态。
- 手机数字谱向下延伸至播放控制栏上方。音频加载时，底部箭头和加载提示可同时完整显示。
- 数字谱采用正方形键位格，数字随格宽调整。长押起点标绿、终点标红，格内保留音符编号。

本次发布提供 GitHub 生成的源码 ZIP 和 tar.gz。手机打开歌曲后，点击右侧的「数字谱」即可试用。[《[E]》EXT 在线示例](https://ub.thregren.world/share/576b9bc69d6639b1.html?chart=EXT)
