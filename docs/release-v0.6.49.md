# v0.6.49

本版修复节奏轴拖动、自动滚动和暂停后残留画面造成的拖影，让节拍线与 marker 在连续播放和静止时保持清晰。节奏轴新增可选的「全部 marker 合并一行」展示，减少多行 marker 相互遮挡；该展示默认关闭，可在「节奏轴」分类中勾选开启。

提升了旧版 Safari 的音源兼容性。iOS 15 会自动使用原生音频播放 Opus-in-CAF 音源，避免 WebM/Opus 播放不稳；站点可生成对应的 CAF 与 WebM 兼容音源，普通浏览器继续使用现有的 Ogg 音源。相关生成与校验说明见 `deploy/README.md`。

另外同步了网站入口与歌曲分享页的前端资源，修复内联筛选控件的主题配色，并让分享页随首页一起更新。轻量客户端仍支持首次启动后导入曲库压缩包或目录，桌面端和 Android 使用同一份资源包完成增量更新。

提供 Windows、macOS、Linux 的 x64/ARM64 六份轻量客户端和 Android APK。安装包不包含曲库；可从 [夸克网盘](https://pan.quark.cn/s/e9c12157e039) 获取现有的独立完整曲库并导入。Android APK 与上一发布版使用相同签名，可覆盖升级。

已通过仓库自动检查、分享链接与筛选界面检查、节奏轴交互测试和桌面打包结构校验；Android APK 已核对包名、版本与签名。未逐一在所有目标系统和真机上启动测试；macOS 程序未做商业签名。
