# v0.6.30：设置分类与自动循环试听

设置面板按「播放与声音」「Marker 与高亮」「音符序号」「节奏轴」归类，兼容窄屏，保留原有设置和偏好。移除移动端右上角多余的「曲库」文字。

新增「选曲后自动循环试听」开关，默认关闭。开启后，选择曲目会等待原试听片段加载并循环播放；没有试听片段时保持静音，不使用完整音源替代。切歌、开始谱面播放或停止时取消旧试听，快速切歌不会串音。

修复太鼓和比利音效在加载失败后无法重试、音频上下文暂停后漏音的问题，限制并发解码并避免过期结果覆盖当前选择。

提供 Windows x64/arm64、macOS x64/arm64、Linux x86_64/arm64 和 Android 轻量安装包，不内置曲库。可继续导入 v0.6.29 独立曲库包；桌面拖入 ZIP 或选择目录，安卓使用系统文件选择器。自定义音效需要相应资源。

附件包含逐文件 SHA-256 校验清单。桌面包沿用现有分发方式：macOS 未公证，Windows 未使用商业代码签名；Android 沿用原签名以支持覆盖升级。
