# v0.7.10 · 发布恢复与网页版物量图优化

本次为源码发布，提供 GitHub 自动生成的源码归档；不包含客户端安装包或曲库。已有客户端不会自动获得本版修复。

- 分卷包及公共包通过代次切换发布，保留现有路径；加入打包互斥、中断恢复和可选 CRC 校验，公共包补齐可选背景资源。
- Electron 前端更新使用独立快照；云部署增加本地分卷哈希校验和远端激活恢复，降低中断后版本混用的风险。
- 物量图避免同尺寸画布的重复重设，保留现有物量统计逻辑；新增手机触屏拖动以及曲库排序、筛选和换库的浏览器回归。
- 改善音频转码空间估算、ZIP 额外成员统计和 Android 本地服务异常诊断。

包的代次发布要求文件系统支持创建符号链接；Windows 上还需要相应权限，本次未进行 Windows 验证。云部署恢复使用本地模拟验证，未在生产环境演练中断。

验证包括包发布与恢复的本地测试、物量图和曲库相关单元测试、桌面及模拟手机浏览器回归。遵照本次要求，未测试变速模块；发布提交的自动 CI 被跳过，因此本次不宣称完整 CI 通过。触屏验证为 Chromium 模拟，尚未在实体手机或移动 Safari 上验证。
