# v0.6.27 · 稳定性、安全与资源管理

修复异常谱面时间可能卡住物量绘图、音频解码队列保留旧缓冲、切歌后旧恢复回调干扰播放的问题。合成音效复用有上限的噪声缓冲，曲库响应按版本复用序列化和压缩结果。

修复 Android 导入失败时的路径别名与回滚保护，Electron 与 Android 的设置改为应用持久存储；本地服务限制 Host 和 Origin。PHP 正确提供 PWA manifest；媒体缓存和缩略图采用更可靠的源身份与原子发布，HTTP 错误和提前 EOF 正确结束响应。

桌面及资源包减少重复哈希载荷，构建与打包互斥，失败保留旧产物。沿用 0.6.26 的逐成员内容校验和历史资源保护，补充复制资源的身份检查。桌面构建依赖加入有明确来源和许可证的 sprintf 修补包。

保留横向节奏轴、现有曲库和已发布的查看器交互。六份桌面附件为不带曲库的轻量包，分别覆盖 macOS、Windows 和 Linux 的两种架构；运行时请选择自己的 site 目录。macOS 包未经公证，Windows 跨平台构建未签名。

发布前通过 79 项真实界面检查、18 项横向节奏轴检查及源站 PHP 的 32 项 HTTP 检查。播放中切换速度的自动续播已补充回归验证。
