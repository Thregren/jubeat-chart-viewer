这一版把「看谱面」和「练某一段」的体验补齐：**序号外观可调**、**A–B 段落循环**、
**手机锁死页面缩放**，并把**倍速档位**做细。桌面版 Release 附件照旧是不含曲库的轻量包。

## 音符序号外观（字号 / 透明度 / 位置）

序号以前是写死的大小和位置，面板一大就显得小、密的地方又挡住 marker。
现在选项区多了三个控件，改完立刻生效并记住：

| 控件 | 范围 | 默认 |
|---|---|---|
| 序号字号 | 50% – 200%（滑杆，步进 5%） | 100% |
| 序号透明度 | 10% – 100%（滑杆，步进 5%） | 100% |
| 序号放右下角 | 开 / 关 | 关（画在格子正中） |

字号和透明度都乘在原有的「同押光晕数字」上，所以调小之后光晕、描边、外扩波纹会一起变淡，
不会出现「数字淡了光晕还很亮」的割裂感。录制模式（`?rec=1`）里这三项被固定成默认值，
免得录制机器上残留的滑杆设置混进成片。

## A–B 段落循环

控制条上新增 `A-B` 按钮（等价于键盘 `A`），一个键按三下走完一个循环：

1. 第一下：在当前位置打 **A**
2. 第二下：打 **B**，立刻开始 `A → B` 循环
3. 第三下：清掉 A、B，恢复正常播放

另外两条防呆规则：

- **有打点时拖动进度条会清空所有打点**——拖着找位置时最容易被「循环」拽回去，
  所以拖动本身就是「我要换位置」的信号
- **换曲 / 换难度也会清空**——A、B 是打在具体谱面上的时间点，换谱面之后留着只会错位

物量条上会把 A–B 区间画成高亮，循环范围一眼可见。

## 手机锁死页面缩放

手机上误触捏合会把整个页面放大，4×4 面板和进度条就跑出屏幕了。现在四道防线：

- `viewport`：`maximum-scale=1, user-scalable=no`
- CSS：`touch-action: pan-x pan-y`（掐掉捏合，保留单指拖动）
- `lockZoom()`：拦掉 iOS Safari 不认 `viewport` 时的 `gesturestart/gesturechange/gestureend`
- 同一个 `lockZoom()` 里再拦多指 `touchmove`、双击缩放、`ctrl + 滚轮` 缩放

（桌面浏览器的 `ctrl + 滚轮` 缩放也一起拦掉了，免得把面板顶出可视区。）

## 倍速档位

`0.25× / 0.5× / 0.75× / 1× / 1.25× / 1.5× / 2×`。
新增 0.25× 和 1.25×，去掉原来的 3× 和 4×（那么快的速度看不出判定帧，留着只会误触）。
