# v0.6.40

侧栏移除「重新读取」，Marker 图选改为单列行；切换保音调播放速度时保留当前位置、清理旧媒体缓冲，等跳转就绪后续播并重新安排打点音，修复慢速切回常速后的节拍错位。

本版包含 v0.6.39 的架构、性能和统计修复：

- 曲库版本索引最多四路并发，保持曲目顺序，使用内容哈希缓存。
- 音频解码前检查时长、声道与 PCM 预算；变速和超预算音源走原生媒体，及时释放 PCM。
- Marker 无损图集与构建期透明度计算，默认动画资源从 40 次下载减为 2 次；保留原帧兼容路径。
- 画布采用设备像素预算，录制保留原精度；辅助文字最多 10 Hz，暂停无持续绘制。
- 曲库、音频、渲染和设置服务统一生命周期；慢网深链接等待真实加载结果。
- 加入索引累计预算、图片尺寸、Marker 时间参数和录制画幅校验。
- 访客事件有限重试、稳定 ID 幂等去重、短事务与持久事件表；日志失败可恢复，保留旧计数和身份。
- CI 增加浏览器回归和发布后只读安全检查。

README 现按主要功能、访问与下载、最近更新、主要架构排列，并更新桌面、手机和 Marker 列表截图；完整技术说明保存在开发参考文档。

提供 Windows / macOS / Linux 的 x64、ARM64 六份轻量程序和 Android APK。完整曲库单独提供 `jubeat-library-0.6.40.zip`，包含 2459 个条目、7343 张谱面，桌面与 Android 使用同一个资源包。

验证覆盖 Node/Python 完整检查、独立 PHP/SQLite HTTP 回归、桌面和手机浏览器的筛选、切歌、暂停空闲、图集像素、0.5×／0.75× 反复返回 1×。各平台产物校验版本、内部资源和 SHA-256；未宣称所有操作系统与真机均已启动测试。

所有程序和曲库的校验值见同版 SHA-256 清单。曲库、歌曲封面和其他素材不加入公开源码仓库。
