# v0.7.13 · OFT 回放匹配优化

本次发布 GitHub 源码归档，网页版同步更新。

- 导入 OFT 时，打开已匹配的谱面会复用浏览器刚读到的谱面。WONDER WALKER EXT 样本在冷缓存下由 3 次谱面请求降为 2 次。
- 新导出的 JBR2 精简回放会记录歌曲与难度提示。提示有效时只需要读取 1 张谱面，仍会逐个核对 marker 的格位和时间。提示失效时自动回到完整搜索，旧版 JBR1 可以继续导入。
- 保留每个 marker 的判定和偏差，以及分数与连击时间线。导入、解析和导出在浏览器内完成。
- 实测与验收边界见 [OFT 回放匹配优化](OFT回放匹配优化.md)。
