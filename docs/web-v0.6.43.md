# 网页版 v0.6.43

在「Marker 与外观」中切换 13 套基于街机版本素材的界面主题，从初代、ripples、knit、copious、saucer、saucer fulfill、prop、Qubell、clan、2020、festo、Ave 到 beyond the Ave。默认样式保持不变；选择会记住，录制模式使用固定默认外观。配色与装饰依据各版本素材适配网页，并非游戏本体动效的逐帧复刻。尊重系统减少动态效果设置。素材来源与摘要见 [theme-assets.json](theme-assets.json)。

性能和可靠性：

- 快速切换 Marker 后取消的帧可以重新加载；调整画布大小时复用物量统计。
- 加载谱面失败时清除旧谱并禁用播放、分享；音效关闭时停掉排程定时器。
- 取消过期解码排队并在解码卡住时使用媒体回退，减少快速切歌的内存堆积。
- 访客统计在读取曲库前执行限流；Android 曲库导入限制文件类型，Electron 恢复记录校验严格限定临时目录。
- 更新 Electron 与构建依赖，解决 npm 审计报告的证书与依赖安全问题。

原有曲库和访客数据不需要迁移。桌面及 Android 客户端源代码已更新，现有 v0.6.40 安装包不包含本次更新。
