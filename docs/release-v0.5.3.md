这一版把 marker 默认节奏、桌面端高度稳定性和前端热路径一起收了一遍。重点不是加功能，
而是让曲库、切歌、切难度和长时间播放都更省资源、更不容易抖。

## marker 动画

- **默认动画速度改为 0.8×**：接近动画稍微慢一点、更容易看清展开过程
- 引入设置版本 4：旧浏览器会自动吃一次新默认值；之后手动改过的动画速度仍会继续记住
- 默认按键动画仍是 `#04 Shutter + frame`

## 桌面端布局稳定

之前桌面端选项区在正常文档流里，展开 / 收起会让控制条高度相差约 200px，中间的铺面跟着
一高一矮；矮窗口下甚至会把面板挤到没地方放。

- **桌面端选项区改成控制条上方的浮层**，展开时不再挤压铺面高度
- `fitPanel()` 补上说明文字的 margin 计算，避免面板上下被裁掉几像素
- 同时观察 `.panel-stage` 的实际尺寸，歌曲信息 / 窗口尺寸变化后都会重新取最终高度

实测展开和收起时面板尺寸一致：

| 窗口 | 面板 |
|---|---|
| 1440 × 900 | 560 px |
| 1280 × 768 | 428.5 px |
| 1100 × 650 | 310.5 px |

## 前端性能

- **同一首歌不再下载两份音源**：以前 WebAudio 的 fetch/解码会和 `<audio>.load()` 同时进行；
  现在优先只 fetch 一次，解码失败或 `?media=1` 时才回落 `<audio>`
- **同曲切难度复用 AudioBuffer**，不会为了换个谱面把音源重新下载 / 解码
- 修正 WebAudio 模式下 `rawMediaTime()` 仍读取空 `<audio>.currentTime` 的问题，打点音排程位置更可靠
- **物量条静态层缓存**：背景 / 网格 / 柱子只在谱面或尺寸变化时绘制，每帧只合成播放头
- **note 推进改成游标 + activeNotes**：不再每帧扫描完整谱面，只处理正在闪烁 / 长押的 note
- 曲库列表：
  - 选曲只更新 active 行，不重建整张列表
  - 搜索字段、难度映射和长押状态只计算一次
  - 可视区外的行使用 `content-visibility: auto`，减少布局和绘制
- 缓存 hold 倒计时节点；时间、hold 进度和倒计时文本只在内容变化时写 DOM

## 验证

- `tools/smoke_test.py`：29 项通过
- `tools/php_smoke_test.py`：21 项通过
- 浏览器复验：切曲、切难度、播放 / 暂停正常；同一首歌只观察到一次音源 fetch
- 前端静态资源版本：`0.5.24`

## 部署 / 更新

服务器上更新前端传这四个文件，曲库不需要重传：

```
铺面查看器/player/static/index.html   →  <站点根>/index.html
铺面查看器/player/static/app.js       →  <站点根>/static/app.js
铺面查看器/player/static/style.css    →  <站点根>/static/style.css
铺面查看器/player/static/sfx.js       →  <站点根>/static/sfx.js
```

Release 附件仍是**不带曲库**的桌面轻量包。解压后直接运行；首次启动用菜单
「文件 → 选择站点目录（site/）」指向自己构建的 `site/`。
