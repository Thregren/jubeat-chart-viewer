# v0.6.50

本版加入歌曲背景故事阅读入口，并把长押练习辅助与本地完整曲库打包一起完善。

- 新增「背景故事」按钮。曲目有对应资料时，可在播放器内阅读版本沿革、艺人、收录位置、资料来源和核验边界；没有可靠映射的资料不会强行挂到歌曲上。
- 新增「长押结束倒计时」开关。开启后，长按期间显示保留一位小数的剩余秒数；倒计时会避开音符顺序数字，二者分别占用格内中央和右下角。
- 修正 Windows 上音符序号与长押倒计时使用衬线字体的问题，统一改用跨平台无衬线 Canvas 字体回退。
- 修正部分背景故事长标题在面板左侧被裁切的问题，限制标题、正文和弹窗网格的最小宽度；桌面与窄屏均可换行阅读。
- 完整曲库压缩包现在包含 `data/background-stories.json`，桌面端与 Android 导入同一资源包后也能离线查看背景故事；资源包同时接受 Markdown 资料文件。

曲库共 **2469 个歌曲／谱面版本条目、7373 张谱面、17270 个资源**。背景资料来自 **16 篇版本研究文档，共 2449 篇歌曲文章**；**2437 篇**可唯一映射到统一曲库条目，**12 篇**因缺少安全唯一的标题或 ID 匹配保留为未映射，不使用猜测补齐。

提供 Windows、macOS、Linux 的 x64/ARM64 六份轻量客户端和 Android APK。安装包不包含曲库。**GitHub 附件中的 `web-0.6.50.part001.zip` 至 `part015.zip` 是网站部署用的独立分卷，不是多卷压缩包，也不能导入客户端。**客户端与 Android 共用的完整曲库 `jubeat-library-0.6.50.zip` 请从[夸克网盘](https://pan.quark.cn/s/e9c12157e039)下载。Android APK 与上一发布版使用相同签名，可覆盖升级。

本版已验证平台偏好白名单、长押倒计时位置与字体、背景故事标题布局、曲库 ZIP 的内容与 CRC、六份桌面包结构和 Android APK 签名。未逐一在所有目标系统和真机上启动测试；macOS 程序未做商业签名。
