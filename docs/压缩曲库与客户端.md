# 压缩曲库、网页发布与轻量客户端

v0.6.29 使用本地统一库生成独立的精简网页库，网站、Windows/macOS/Linux 轻量客户端和安卓共用。WAV 母库不修改，仍保存原始谱面、精确事件和来源记录。生成、运行均不读取旧 MCZ 曲库或旧封面/等级缓存。

## 内容与适用范围

| 文件 | 母库保留 | 网页/客户端发布 |
| --- | --- | --- |
| 完整音频、原试听 | WAV | Ogg Opus 80 kbps VBR |
| 封面 | 本地原始 PNG | 同一份本地 PNG，不取网页封面 |
| 列表缩略图 | 不要求 | 96px JPEG，quality 82 |
| 播放谱面 | MC兼容JSON、精确事件、原始二进制 | 兼容JSON，仅调整音频文件名 |
| 来源、核对证据和日志 | 保留 | 不发布 |
| UI 和 Marker | 独立素材 | 播放所需文件 |

编码参数与旧网页一致：libopus，80 kbps，VBR，application audio，20ms帧，compression level 10，48kHz。原试听单独转码，不从正曲开头临时截取。压缩库不含 WAV、MCZ、`.mc`、精确事件、原始二进制或解包日志。

本工具适用于解包工具已经输出的 jubeat 至 beyond the Ave.、plus、jukebeat 开放目录库，也支持具备本地播放资源的独立版本；不负责解密原游戏输入。本批共17个分类、2457个歌曲/谱面版本条目、7329张谱面。相同谱面合并、谱面变化另留，jukebeat去重后无独立新增条目。209组特殊资源已移除。

音乐魔方21首只有EXT，来自用户提供的视频复核抄谱，不能视作原生时钟谱面提取；缺少BSC、ADV和原试听。正常条目仍有1份完整音频、22份原试听、3张封面缺失，缺失标记继续保留。26个条目的曲名、62张谱面的等级尚未确认，不伪造信息。

## 从母库转码

需要 Python 3、Pillow、ffmpeg、ffprobe。`--library` 为已由母库导出的 WAV 开放目录库，`--master` 为母库。程序核对音频、封面和兼容谱面的来源，输出必须独立于输入和母库。

```sh
python3 tools/compress_directory.py \
  --library /path/to/wav-directory-library --master /path/to/unified-master \
  --out /path/to/web-library --report /path/to/private-reports --jobs 4
node tools/verify_directory.cjs /path/to/web-library /path/to/report.json
python3 tools/serve.py /path/to/web-library --port 8124
```

断点记录放在报告目录；相同输入和参数可以续跑。转码失败即停止，不会用WAV冒充OGG或回退到旧库。精确事件保留在母库，压缩库不改变可玩音符和时序。播放器界面不增设素材面板；原试听按钮在播放控制行最右，有资源则循环，再按停止，没有则隐藏。

## 完整曲库与服务器分卷

```sh
python3 tools/pack_web_library.py --library /path/to/web-library \
  --output /path/to/packages --version 0.6.29 --volume-mib 256
```

- `jubeat-library-0.6.29.zip`：完整客户端曲库，包含data、songs、markers，不带UI、MCZ或歌曲原始文件。桌面与安卓使用同一份。
- `web-0.6.29.partNNN.zip`：约256MiB一卷的独立ZIP，各自可解压。它们不是需要拼接的多卷ZIP，不能把单个发布分卷导入客户端。
- `packages.json`、`SHA256SUMS`：记录每份包的大小、文件数、SHA256及CRC校验状态。

先本地校验，再逐卷上传COS的独立版本前缀。服务器逐卷下载、核对SHA256、解压到新站点目录、删除临时卷；完整验证后切换，再删除旧曲库。凭证与临时下载链接不得放入Git、Release或公开网页目录，不覆盖COS其他业务文件。

## 桌面端

解压对应平台轻量程序并启动，把完整曲库ZIP拖进窗口，或选择“文件→导入曲库资源包”。程序先暂存并校验CRC、路径和所有显式资源，完整后切换自己的库，失败恢复旧库。导入完成可离线使用。

也可拖入已解压的完整曲库文件夹，或通过文件菜单选择；程序会将配套UI复制到该文件夹。ZIP导入使用系统应用用户数据目录。程序与曲库可分别更新，更新时需容纳旧库、新库和暂存。

```sh
WORK=/tmp/jubeat-build sh tools/pack_desktop.sh
```

支持Windows x64/arm64、macOS Intel/Apple Silicon、Linux x86_64/arm64。轻量包自带UI，不带`site/`歌曲。Mac未作商业签名，首次可在Finder中右键“打开”；Linux AppImage可能需要先赋予执行权限。

## 安卓端

安装`jubeat-viewer-0.6.29-android-min.apk`，点“导入资源包”，从系统文件选择器选择同一个完整曲库ZIP。不需要Python或MCZ转换器。APK自带UI，每次启动更新前端，曲库包不重复携带UI。

资源默认存放于`Android/media/world.thregren.jubeatviewer/site`，写入失败则回退到应用私有目录。也可通过电脑解压到这个目录，再点“重新检测”。

```sh
sh android/build.sh
```

需要SDK platform34、build-tools35.0.0、JDK21，路径可用`ANDROID_HOME`和`JAVA_HOME`覆盖。支持空格和中文仓库路径。首次构建生成本地发布密钥和随机密码，以后复用；请备份`android/keystore/`，该目录被Git忽略，不能上传网盘或Release。

## 验证与分发

`tools/check.sh --full`覆盖播放器、平台、Range、导入事务和端到端接口；`test_compress_directory.py`用真实ffmpeg验证转码和精简输出；`test_library_import.mjs`覆盖UTF-8路径、CRC、越界路径、缺失资源及中断恢复。实际全库另用`verify_directory.cjs`逐谱面核验。

GitHub只发布程序源码、中文说明、轻量安装包和校验清单；独立完整压缩曲库放网盘。原始游戏输入、母库、签名材料、私有配置和临时链接均不进入公开Git。

COS/TAT发布命令（需要已有tccli登录、COS Python SDK和明确的服务器目标）：

```sh
python3 tools/deploy_cos.py --packages /path/to/packages --report /path/to/private-reports \
  --bucket YOUR_BUCKET --region YOUR_COS_REGION --prefix jubeat/v0.6.29 \
  --instance YOUR_INSTANCE --instance-region YOUR_INSTANCE_REGION \
  --target /www/wwwroot/YOUR_DOMAIN --activate
```

默认上传并暂存验证；显式`--activate`才切换并删除旧站点。`--mode upload/stage/activate`可拆分执行。目标服务器需有Python3、curl、现有宝塔Nginx站点及`www`用户；新`songs/`路由复用该站点现有`media/`路由规则。
