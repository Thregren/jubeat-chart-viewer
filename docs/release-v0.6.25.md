# v0.6.25 · 横向节奏轴与资源管理优化

新增默认隐藏的横向节奏轴，按 16 个面板位置展示音符和长押，支持四分拍线及其 2 / 3 / 4 等分、4 / 8 / 16 拍视野。桌面宽屏与物量条共存；宽度不超过 600px 时覆盖物量条，避免挤占面板。拖动可定位，焦点在节奏轴时方向键按所选细分移动。刷新后恢复隐藏。对应 #1。

合入本地积累的性能与稳定性优化：曲库列表仅绘制可见行，谱面、marker 帧和音频解码使用有上限的缓存与队列；构建支持增量索引、取消和原子回滚；桌面与开发服务器收紧资源路径、连接和文件读取限制；Android 资源导入增加预算、校验、取消与失败恢复。同步整理录制页面布局与卡片接口，并修复桌面端快速切换难度时旧请求取消后仍发送文件的异常。

README 已更新使用说明和截图。完整发布检查通过；PHP 检查因构建机未安装 PHP 而跳过。跨平台包会校验归档完整性、应用版本与运行时架构；实际界面测试在 macOS arm64 上进行。

[在线网站](https://ub.thregren.world/) 已更新，可展开底部选项并点击“节奏轴”试用。六份 GitHub 附件是**不带曲库的轻量桌面包**，首次启动需选择自己的 `site/`；带曲库全量包单独提供于[夸克网盘](https://pan.quark.cn/s/e9c12157e039)。
