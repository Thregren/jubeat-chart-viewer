# 能力图校准：Conflict EXT

新增音乐魔方《Conflict》EXT 的官方截图样本。统一曲库谱面共有 764 个头判和 51 个长押尾判，与截图显示的 815 判定数一致。以截图六边形外圈为 100，从蓝色线中心估读：物量 86.5、尖峰 102.6、钢琴 178.9、出张 17.3、长押 82.4、同时押 28.3。截图线宽和网格定位带来约数个百分点的误差。

钢琴通用估算使用同样的直线连键特征，映射由 `1.15237138 × 连键率²` 调整为 `0.9956 × 连键率^1.2`，减轻密集钢琴谱被平方项过度放大的问题。Conflict 旧估计约 310.3，新估计约 180.4。其余五轴的通用公式暂未修改。

对 23 张参与模型选择或拟合的截图，以外圈为 100，钢琴轴平均绝对误差从 12.11 降到 7.98；原有 22 张则由 6.69 增至 8.27。模型选择与样本并不独立，以上误差不能代表全曲库效果。既有截图样本按完整谱面指纹匹配时显示实测轮廓；新增 Conflict 也同样处理。修改头判位置、时间或长押信息的谱面不会套用这一轮廓，而会回退至通用估算。该估算不是已知官方公式。
