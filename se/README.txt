打点音素材（可选，自己往这个目录里丢文件即可）
==============================================

前端「打点音」默认是 WebAudio 实时合成的。如果你想要真实音效，把音频文件放到这个
目录里，文件名按下表命名，构建时会被复制到 site/media/se/，播放器优先用它们：

    clap.ogg    拍手
    nyan.ogg    猫娘 nyan（比如 Miku 的「喵」）
    don.ogg     太鼓「咚」（重音拍）
    ka.ogg      太鼓「咔」（其他拍）

前端「按键音效」下拉里还有一项「比利·海灵顿」，也是一组两个音：

    billy-accent.ogg   重音拍（小节第一拍）
    billy-normal.ogg   其他拍

支持 .ogg / .oga / .mp3 / .wav / .m4a / .flac，随便挑一种就行（同名的优先 ogg）。
没放的会单独回落到合成音，也就是说你只放 don/ka 也可以。

注意
----
* 这个目录被 .gitignore 排除（只保留本说明），因为从游戏里截的音效、声库素材
  都是有版权的，不适合放进公开仓库。
* 本地构建 / 桌面版 / PHP 整包都会带上这些文件；想更新就重新跑一次：

      python3 tools/build_site.py --out site --prune
