打点音素材（可选，自己往这个目录里丢文件即可）
==============================================

前端「按键音效」默认是 WebAudio 实时合成的。如果你想要真实音效，把音频文件放到这个
目录里，文件名按下表命名，构建时会被复制到 site/media/se/，播放器优先用它们：

    don.ogg     太鼓「咚」
    ka.ogg      太鼓「咔」

现在只有 点击 / 太鼓 两组音色，每组有 普通 / 16 分及更密 / 同押 三档；
三档都由同一基础素材或同族合成音派生，不再需要 `-16` 文件，也不再有按拍位交替
的两个音（旧的重音 / 普通轮换已移除）。所有档位响度统一，差异靠音高、时长、
重复次数和频谱体现。只有太鼓用真素材，点击是纯合成音；「拍手」组已按用户要求删除，
旧设置会自动迁移到点击。素材缺失时整档回落到合成音。

支持 .ogg / .oga / .mp3 / .wav / .m4a / .flac，随便挑一种就行（同名的优先 ogg）。
没放的会单独回落到合成音，也就是说你只放 don/ka 也可以。

注意
----
* 这个目录被 .gitignore 排除（只保留本说明），因为从游戏里截的音效、声库素材
  都是有版权的，不适合放进公开仓库。
* 本地构建 / 桌面版 / PHP 整包都会带上这些文件；想更新就重新跑一次：

      python3 tools/build_directory.py --library <曲库目录> --out site

  构建入口只认 `--library` / `--out` / `--no-markers`。
