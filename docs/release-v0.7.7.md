# v0.7.7 · 长押封面动画与启动页优化

仅源码发布：提供 GitHub 自动生成的 Source code ZIP / tar.gz，不附客户端安装包、曲库或站点资源包。

- 歌曲列表中，包含长押谱面的歌曲封面右上角显示长押动画；查看器封面的标记跟随当前难度显示。

- 启动页的 4×4 面板静音循环展示 FLOWER EXT 谱面；曲库缺失时保留静态图案。
- 修复手机首次打开时曲库侧栏短暂弹出的问题。
- 移除网站对系统“减少动态效果”的特殊处理。

验证：手机和桌面多档宽度、14 个主题、长押标记与难度切换、启动页动画及线上资源已检查。源码发布检查以本版提交的 GitHub CI 结果为准。
